🧠 Блок 1. Изучение нового материала

🌍 Разминка: где работают синус, косинус и тангенс?

Представь, что ты проектируешь пандус для входа в здание. Нужно понять, какой длины он должен быть при заданной высоте и угле наклона, чтобы подъём был безопасным. Или ты рассчитываешь угол отскока шара в бильярде. Во всех этих случаях на помощь приходят точные соотношения между сторонами и углами — синус, косинус и тангенс!

📖 Основные определения (пункт 74)

Прямоугольный треугольник ABC с прямым углом C. Для острого угла A:

  • Синусом (sin) называется отношение противолежащего катета к гипотенузе.
  • Косинусом (cos) называется отношение прилежащего катета к гипотенузе.
  • Тангенсом (tg) называется отношение противолежащего катета к прилежащему.

Прямоугольный треугольник ABC (∠C = 90°)

sin A = a / c     cos A = b / c     tg A = a / b

Важные следствия из подобия:

  1. Если острые углы двух прямоугольных треугольников равны, то синусы, косинусы и тангенсы этих углов равны (треугольники подобны, а отношения сторон сохраняются).
  2. Тангенс можно выразить через синус и косинус: tg A = sin A / cos A.

🌟 Основное тригонометрическое тождество

Докажем, что для любого острого угла α выполняется равенство:

sin²α + cos²α = 1

Доказательство. Пусть в прямоугольном треугольнике катеты равны a и b, гипотенуза равна c. Тогда sin α = a/c, cos α = b/c.
Сложим их квадраты: sin²α + cos²α = (a/c)² + (b/c)² = (a² + b²) / c².
По теореме Пифагора a² + b² = c². Значит, (a² + b²) / c² = c² / c² = 1. Что и требовалось доказать. ✅

📐 Значения для углов 30°, 45° и 60° (пункт 75)

Треугольник 30°–60°–90°

Угол α30°45°60°
sin α1/2√2 / 2√3 / 2
cos α√3 / 2√2 / 21/2
tg α√3 / 31√3

💡 Подсказка: заметь, что sin 30° = cos 60°, а sin 60° = cos 30°. Это общее правило: синус угла равен косинусу его дополнения до 90°.

🛠 Блок 2. Закрепление (задачи из учебника)

Сначала реши задачу в тетради, потом открой решение и проверь каждый шаг!

Базовый уровень

Задание 1 (№697, а, б)

Найдите синус, косинус и тангенс острых углов треугольника ABC с прямым углом C, если: а) BC = 8, AB = 17; б) BC = 21, AC = 20.

Показать подробное решение
Шаг 1 (случай а): Дано: BC = 8 (противолежащий катет для угла A), AB = 17 (гипотенуза).
По теореме Пифагора найдём AC: AC = √(AB² − BC²) = √(17² − 8²) = √(289 − 64) = √225 = 15.
Шаг 2: Вычисляем соотношения для угла A:
sin A = BC / AB = 8/17;
cos A = AC / AB = 15/17;
tg A = BC / AC = 8/15.
Шаг 3 (для угла B): Катеты меняются ролями (BC теперь прилежащий, AC — противолежащий):
sin B = AC / AB = 15/17;
cos B = BC / AB = 8/17;
tg B = AC / BC = 15/8.
Шаг 4 (случай б): Дано: BC = 21, AC = 20.
AB = √(21² + 20²) = √(441 + 400) = √841 = 29.
sin A = 21/29, cos A = 20/29, tg A = 21/20.
sin B = 20/29, cos B = 21/29, tg B = 20/21.
Ответ: а) sin A = 8/17, cos A = 15/17, tg A = 8/15; sin B = 15/17, cos B = 8/17, tg B = 15/8. б) sin A = 21/29, cos A = 20/29, tg A = 21/20; sin B = 20/29, cos B = 21/29, tg B = 20/21.
✅ Проверка: tg A должен быть равен sin A / cos A. В случае а: (8/17) / (15/17) = 8/15. Совпадает!
Базовый уровень

Задание 2 (№699, а, б)

Найдите sin α и tg α, если: а) cos α = 1/2; б) cos α = √3 / 2.

Показать подробное решение
Шаг 1 (случай а): Используем основное тригонометрическое тождество: sin²α = 1 − cos²α.
sin²α = 1 − (1/2)² = 1 − 1/4 = 3/4.
Так как α — острый угол, sin α > 0, значит sin α = √3 / 2.
Шаг 2: tg α = sin α / cos α = (√3 / 2) / (1/2) = √3.
Шаг 3 (случай б): cos α = √3 / 2.
sin²α = 1 − (√3 / 2)² = 1 − 3/4 = 1/4. Значит sin α = 1/2.
tg α = (1/2) / (√3 / 2) = 1 / √3 = √3 / 3.
Ответ: а) sin α = √3 / 2, tg α = √3; б) sin α = 1/2, tg α = √3 / 3.
✅ Проверка по таблице: при cos α = 1/2 угол α = 60°, sin 60° = √3/2, tg 60° = √3. При cos α = √3/2 угол α = 30°, sin 30° = 1/2, tg 30° = √3/3. Всё верно!
Средний уровень

Задание 3 (№704)

Найдите площадь равнобедренного треугольника с углом при основании α, если: а) боковая сторона равна b; б) основание равно a.

Показать подробное решение
Шаг 1 (случай а): Пусть дан △ABC с основанием AC и боковыми сторонами AB = BC = b. Угол при основании ∠A = α.
Проведём высоту BD к основанию AC. В прямоугольном △ABD (∠D = 90°):
высота BD = AB · sin α = b · sin α;
отрезок AD = AB · cos α = b · cos α.
Шаг 2: Так как треугольник равнобедренный, высота BD является и медианой, поэтому AC = 2 · AD = 2b · cos α.
Площадь S = ½ · AC · BD = ½ · (2b · cos α) · (b · sin α) = b² · sin α · cos α.
Шаг 3 (случай б): Дано основание AC = a. Тогда AD = a / 2.
Из △ABD: высота BD = AD · tg α = (a / 2) · tg α.
Площадь S = ½ · AC · BD = ½ · a · ((a / 2) · tg α) = (a² / 4) · tg α.
Ответ: а) S = b² · sin α · cos α; б) S = (a² / 4) · tg α.
Средний уровень

Задание 4 (№708)

Стороны прямоугольника равны 13 см и 13√3 см. Найдите углы, которые образует диагональ со сторонами прямоугольника.

Показать подробное решение
Шаг 1: Пусть стороны прямоугольника ABCD: AB = 13√3 см, BC = 13 см. Диагональ AC делит прямоугольник на два прямоугольных треугольника.
Шаг 2: Рассмотрим △ABC (∠B = 90°). Найдём тангенс угла BAC:
tg(∠BAC) = BC / AB = 13 / (13√3) = 1 / √3 = √3 / 3.
Шаг 3: По таблице значений, если tg α = √3 / 3, то α = 30°. Значит, ∠BAC = 30°.
Второй острый угол ∠BCA = 90° − 30° = 60°.
Ответ: диагональ образует со сторонами углы 30° и 60°.
✅ Проверка: гипотенуза AC = √(13² + (13√3)²) = √(169 + 507) = √676 = 26. Тогда sin(∠BAC) = BC / AC = 13/26 = 1/2, что соответствует sin 30°. Всё сходится!
Продвинутый уровень

Задание 5 (№706)

Насыпь шоссейной дороги имеет в верхней части ширину 60 м. Какова ширина насыпи в её нижней части, если угол наклона откосов равен 60°, а высота насыпи равна 12 м?

Показать подробное решение
Шаг 1: Представим поперечное сечение насыпи как равнобедренную трапецию ABCD с основаниями BC (верх) и AD (низ). BC = 60 м. Высота BH = CK = 12 м, угол наклона ∠A = ∠D = 60°.
Шаг 2: Рассмотрим прямоугольный △ABH (H = 90°). Известен катет BH = 12 м и угол A = 60°. Нужно найти катет AH:
tg A = BH / AH ⇒ AH = BH / tg 60° = 12 / √3 = 4√3 м.
Шаг 3: Аналогично в △CKD катет KD = 4√3 м.
Отрезок HK равен верхнему основанию BC: HK = 60 м.
Нижнее основание AD = AH + HK + KD = 4√3 + 60 + 4√3 = 60 + 8√3 м.
Шаг 4: Приближённое значение: √3 ≈ 1,732, значит AD ≈ 60 + 8 · 1,732 = 60 + 13,856 = 73,856 ≈ 73,9 м.
Ответ: 60 + 8√3 м (или приблизительно 73,9 м).
Продвинутый уровень

Задание 6 (№713)

Основание равнобедренного треугольника относится к боковой стороне как 4 : 3, а высота, проведённая к основанию, равна 30 см. Найдите отрезки, на которые эту высоту делит биссектриса угла при основании.

Показать подробное решение
Шаг 1: Пусть дан △ABC с основанием AC, AB = BC. Высота BD = 30 см. По условию AC : AB = 4 : 3.
Пусть коэффициент пропорциональности равен x: AC = 4x, AB = 3x.
Шаг 2: Высота BD в равнобедренном треугольнике является медианой, поэтому AD = AC / 2 = 2x.
Рассмотрим прямоугольный △ABD. По теореме Пифагора: AB² = AD² + BD².
(3x)² = (2x)² + 30² ⇒ 9x² = 4x² + 900 ⇒ 5x² = 900 ⇒ x² = 180 ⇒ x = √180 = 6√5.
Шаг 3: Найдём длины сторон △ABD: AD = 2x = 12√5 см, AB = 3x = 18√5 см.
Пусть биссектриса угла A пересекает высоту BD в точке L. По свойству биссектрисы треугольника она делит противоположную сторону (BD) на отрезки, пропорциональные прилежащим сторонам:
BL / LD = AB / AD.
Шаг 4: Найдём отношение: AB / AD = 18√5 / 12√5 = 18 / 12 = 3 / 2.
Значит, BL : LD = 3 : 2. Всего частей 3 + 2 = 5, длина BD = 30 см. Одна часть = 30 : 5 = 6 см.
BL = 3 · 6 = 18 см; LD = 2 · 6 = 12 см.
Ответ: 18 см и 12 см.
✅ Проверка: 18 + 12 = 30 см — вся высота. 18 / 12 = 1,5 и AB / AD = 18√5 / 12√5 = 1,5. Свойство биссектрисы выполняется!
Дополнительная задача

Задание 7 (№710)

Треугольники ABC и A₁B₁C₁ подобны, AB = 6 см, BC = 9 см, CA = 10 см. Наибольшая сторона треугольника A₁B₁C₁ равна 7,5 см. Найдите две другие стороны треугольника A₁B₁C₁.

Показать подробное решение
Шаг 1: В △ABC наибольшая сторона — это CA = 10 см. Ей соответствует наибольшая сторона C₁A₁ = 7,5 см в подобном треугольнике.
Шаг 2: Найдём коэффициент подобия k = C₁A₁ / CA = 7,5 / 10 = 0,75.
Шаг 3: Остальные стороны △A₁B₁C₁ равны соответствующим сторонам △ABC, умноженным на k:
A₁B₁ = AB · k = 6 · 0,75 = 4,5 см.
B₁C₁ = BC · k = 9 · 0,75 = 6,75 см.
Ответ: 4,5 см и 6,75 см.
Дополнительная задача

Задание 8 (№715)

На стороне BC треугольника ABC взята точка D так, что BD/DC = AB/AC. Докажите, что AD — биссектриса треугольника ABC.

Показать идею доказательства
Шаг 1: Проведём через точку C прямую, параллельную AD, и продолжим сторону BA за точку A до пересечения с этой прямой в точке E.
Шаг 2: Так как AD ∥ CE, по теореме Фалеса (или из подобия △ABD и △EBC): BD / DC = BA / AE.
Шаг 3: По условию BD / DC = AB / AC. Приравниваем правые части: AB / AE = AB / AC, отсюда AE = AC.
Шаг 4: Треугольник ACE равнобедренный (AE = AC), значит ∠AEC = ∠ACE.
Поскольку AD ∥ CE, накрест лежащие углы равны: ∠DAC = ∠ACE, а соответственные углы равны: ∠BAD = ∠AEC.
Следовательно, ∠BAD = ∠DAC — AD делит угол BAC пополам.
Вывод: AD является биссектрисой угла A. Что и требовалось доказать. ✅

🚧 Блок 3. Практическое применение

🗺️ Продукт-задача: «Безопасный пандус»

Ты помогаешь спроектировать пандус для входа в здание. По нормативам максимальный угол наклона пандуса не должен превышать 5°. Высота порога составляет 40 см. Какой минимальной длины должна быть горизонтальная проекция пандуса, чтобы соблюсти норму?

Показать решение инженера
Шаг 1: Модель — прямоугольный треугольник: высота h = 40 см = 0,4 м — противолежащий катет, горизонтальная проекция L — прилежащий катет. Угол α = 5°.
Шаг 2: Используем определение тангенса: tg α = h / L, откуда L = h / tg α.
Шаг 3: По таблицам или калькулятору tg 5° ≈ 0,0875.
L = 0,4 / 0,0875 ≈ 4,57 м.
Ответ: минимальная длина горизонтальной проекции пандуса — около 4,6 метра.
✅ Проверка смысла: при маленьком угле (5°) длина должна быть заметно больше высоты (примерно в 11–12 раз). 4,57 / 0,4 ≈ 11,4. Логично!

⭐ Главное, что нужно запомнить

  • Синус острого угла = противолежащий катет / гипотенуза.
  • Косинус острого угла = прилежащий катет / гипотенуза.
  • Тангенс острого угла = противолежащий катет / прилежащий катет = sin / cos.
  • Основное тригонометрическое тождество: sin²α + cos²α = 1 (следствие из теоремы Пифагора).
  • Значения для 30°, 45°, 60° нужно знать наизусть или уметь быстро выводить из равностороннего и равнобедренного прямоугольного треугольников.
  • Если углы равны, то их тригонометрические функции равны (свойство подобия треугольников).

💡 Методическая подсказка (для учителя или родителя)

  • Типичная ошибка: ученики путают, какой катет «прилежащий», а какой «противолежащий». Лайфхак: «противолежащий» лежит напротив угла (враг), а «прилежащий» прижимается к углу (друг).
  • Для слабых учеников: начните с задач №697 и №699 — здесь нужно просто подставить числа в формулы и воспользоваться таблицей. Обязательно прорисуйте треугольник и подпишите «противолежащий» и «прилежащий» относительно конкретного угла.
  • Про значение «3/2»: напомните, что синус и косинус всегда не больше 1, поэтому «cos α = 3/2» сразу выдаёт ошибку в условии. Это хороший тест на внимательность.
  • Для сильных учеников: задачи №713 и №715 отлично развивают комбинирование свойств (биссектриса + тригонометрия + подобие). Предложите самостоятельно доказать тождество tg α = sin α / cos α, не заглядывая в учебник.
