🧠 Блок 1. Изучение нового материала

🌍 Разминка: самая знаменитая теорема в мире

Строители проверяют прямые углы фундамента с помощью верёвки с 12 узелками — это «египетский треугольник» 3-4-5. Плотники вычисляют длину стропил. Инженеры рассчитывают диагонали экранов. А школьники во всём мире уже 2500 лет учат одну формулу, которая связывает три стороны прямоугольного треугольника. Сегодня мы её выведем и научимся применять! 🏛️

📏 Часть 1. Теорема Пифагора (пункт 60)

🌟 Теорема Пифагора

В прямоугольном треугольнике квадрат гипотенузы равен сумме квадратов катетов: c² = a² + b²

🔎 Доказательство: метод достройки до квадрата

Достраиваем прямоугольный треугольник до квадрата со стороной (a + b), помещая внутрь 4 одинаковых треугольника. В центре остаётся квадрат со стороной c. Считаем площадь двумя способами — и получаем теорему!

💡 Историческая справка

Теорема была известна вавилонянам ещё за 1000 лет до Пифагора (около 2000 лет до н.э.), но именно Пифагор (VI век до н.э.) дал её строгое доказательство. Сейчас известно более 400 различных доказательств этой теоремы — через площади, подобие, векторы и даже дифференциальные уравнения!

🔄 Часть 2. Теорема, обратная теореме Пифагора (пункт 61)

🌟 Обратная теорема

Если квадрат одной стороны треугольника равен сумме квадратов двух других, то треугольник прямоугольный.

Доказательство: строим прямоугольный треугольник с такими же катетами — по прямой теореме Пифагора его гипотенуза равна c. Значит исходный треугольник равен построенному (по трём сторонам), а в нём угол между сторонами a и b — прямой.

🏛️ Египетский треугольник 3-4-5

Древние египтяне натягивали верёвку с 12 узелками (расстояния 3, 4, 5) — и получали идеальный прямой угол для постройки пирамид и разметки полей после разлива Нила.

🌟 Пифагоровы тройки

Самые известные тройки (a, b, c):

3, 4, 5 • 5, 12, 13 • 8, 15, 17 • 7, 24, 25

💡 Любую тройку можно умножить на натуральное число k — получится новая тройка. Например, 3-4-5 × 2 = 6-8-10.

🔎 Общая формула: a = 2k·m·n, b = k·(m² − n²), c = k·(m² + n²), где m > n — любые натуральные числа.

📐 Часть 3. Формула Герона (пункт 62)

🌟 Формула Герона

S = √(p · (p − a) · (p − b) · (p − c))

где p = (a + b + c) / 2 — полупериметр треугольника.

Доказательство опирается на теорему Пифагора: проводим высоту, выражаем её через стороны через два прямоугольных треугольника и подставляем в S = ½ · основание · высота.

💡 Формула названа по имени древнегреческого математика Герона Александрийского (I век н.э.), хотя, возможно, она была известна и раньше.

Задание 1 (№581)

Найдите гипотенузу c прямоугольного треугольника по катетам a и b: а) a = 6, b = 8; б) a = 5, b = 6; в) a = 5/12, b = 1/4; г) a = 8, b = 8√3.

Показать подробное решение
Формула: c = √(a² + b²)
а) c = √(36 + 64) = √100 = 10
б) c = √(25 + 36) = √61 ≈ 7,81
в) c = √((5/12)² + (1/4)²) = √(25/144 + 1/16) = √(25/144 + 9/144) = √(34/144) = √34 / 12
г) c = √(64 + 192) = √256 = 16
Проверка а): 10² = 100 = 6² + 8² ✅
Базовый уровень

Задание 2 (№582)

В прямоугольном треугольнике катеты a и b, гипотенуза c. Найдите b, если: а) a = 12, c = 13; б) a = 7, c = 9; в) a = 12, c = 2b; г) a = 2√3, c = 2b; д) a = 3b, c = 2√10.

Показать подробное решение
Формула: b = √(c² − a²)
а) b = √(169 − 144) = √25 = 5
б) b = √(81 − 49) = √32 = 4√2
в) a = 12, c = 2b → 144 + b² = 4b² → 3b² = 144 → b² = 48 → b = 4√3
г) a = 2√3, c = 2b → 12 + b² = 4b² → 3b² = 12 → b² = 4 → b = 2
д) a = 3b, c = 2√10 → 9b² + b² = 40 → 10b² = 40 → b² = 4 → b = 2
Проверка в): (4√3)² + 12² = 48 + 144 = 192 = (8√3)² ✅
Базовый уровень

Задание 3 (№596)

Выясните, является ли треугольник прямоугольным, если его стороны выражаются числами: а) 6, 8, 10; б) 5, 6, 7; в) 9, 12, 15; г) 10, 24, 26; д) 3, 4, 6; е) 11, 9, 13; ж) 15, 20, 25.

Показать подробное решение
Идея: по обратной теореме Пифагора: если a² + b² = c² (где c — наибольшая сторона), то треугольник прямоугольный.
а) 6² + 8² = 36 + 64 = 100 = 10² ✅ прямоугольный
б) 5² + 6² = 25 + 36 = 61 ≠ 49 = 7² ❌ не прямоугольный
в) 9² + 12² = 81 + 144 = 225 = 15² ✅ прямоугольный (это 3-4-5 × 3)
г) 10² + 24² = 100 + 576 = 676 = 26² ✅ прямоугольный (это 5-12-13 × 2)
д) 3² + 4² = 9 + 16 = 25 ≠ 36 = 6² ❌ не прямоугольный (тупоугольный, т.к. 25 < 36)
е) 9² + 11² = 81 + 121 = 202 ≠ 169 = 13² ❌ не прямоугольный (остроугольный, т.к. 202 > 169)
ж) 15² + 20² = 225 + 400 = 625 = 25² ✅ прямоугольный (это 3-4-5 × 5)
Средний уровень

Задание 4 (№583)

Найдите катеты прямоугольного треугольника, если один из его углов равен 60°, а гипотенуза равна c.

Показать подробное решение
Шаг 1: Второй острый угол: 90° − 60° = 30°.
Шаг 2: Катет, лежащий против угла 30° (это b), равен половине гипотенузы: b = c / 2.
Шаг 3: По теореме Пифагора: a = √(c² − b²) = √(c² − c²/4) = √(3c²/4) = c√3 / 2.
Ответ: b = c/2, a = c√3/2.
Проверка: (c/2)² + (c√3/2)² = c²/4 + 3c²/4 = c² ✅
Средний уровень

Задание 5 (№584)

В прямоугольнике ABCD найдите: а) AD, если AB = 5, AC = 13; б) BC, если CD = 1,5, AC = 2,5; в) CD, если BD = 17, BC = 15.

Показать подробное решение
Идея: диагональ прямоугольника — гипотенуза прямоугольного треугольника, образованного двумя сторонами.
а) AD = √(AC² − AB²) = √(169 − 25) = √144 = 12
б) BC = AD (противоположные стороны). BC = √(AC² − AB²) = √(2,5² − 1,5²) = √(6,25 − 2,25) = √4 = 2
в) CD = √(BD² − BC²) = √(289 − 225) = √64 = 8
Проверка а): 5² + 12² = 25 + 144 = 169 = 13² ✅
Средний уровень

Задание 6 (№585)

Боковая сторона равнобедренного треугольника равна 17 см, а основание равно 16 см. Найдите высоту, проведённую к основанию.

Показать подробное решение
Шаг 1: В равнобедренном треугольнике высота к основанию является медианой, значит делит основание пополам: 16 / 2 = 8 см.
Шаг 2: В прямоугольном треугольнике с гипотенузой 17 и катетом 8: h = √(17² − 8²) = √(289 − 64) = √225 = 15 см.
Проверка: 8² + 15² = 64 + 225 = 289 = 17² ✅ (это пифагорова тройка 8-15-17)

Задание 7 (№589)

По данным катетам a и b прямоугольного треугольника найдите высоту, проведённую к гипотенузе: а) a = 5, b = 12; б) a = 12, b = 16.

Показать подробное решение
Идея: площадь треугольника можно выразить двумя способами: S = ½·a·b = ½·c·h, откуда h = ab/c.
а) c = √(25 + 144) = √169 = 13. h = 5·12/13 = 60/13 ≈ 4,62
б) c = √(144 + 256) = √400 = 20. h = 12·16/20 = 192/20 = 48/5 = 9,6
Проверка а): ½·5·12 = 30; ½·13·(60/13) = 30 ✅

Задание 8 (№590)

Найдите высоты треугольника со сторонами 10 см, 10 см и 12 см.

Показать подробное решение
Шаг 1: По формуле Герона: p = (10 + 10 + 12) / 2 = 16.
Шаг 2: S = √(16 · 6 · 6 · 4) = √(2304) = 48 см².
Шаг 3: Высота к стороне 10: h₁ = 2S / 10 = 96 / 10 = 9,6 см.
Шаг 4: Высота к стороне 12: h₂ = 2S / 12 = 96 / 12 = 8 см.
Ответ: две высоты по 9,6 см (к равным сторонам) и одна 8 см (к основанию).
Проверка: ½ · 12 · 8 = 48 ✅

Найдите сторону и площадь ромба, если его диагонали равны 10 см и 24 см.

Показать подробное решение
Шаг 1: Это равнобедренная трапеция (BC = DA = 13). Проведём две высоты — они отсекут по прямоугольному треугольник у краёв.

Задание 11 (№595)

Одна из диагоналей параллелограмма является его высотой. Найдите эту диагональ, если периметр параллелограмма равен 50 см, а разность смежных сторон равна 1 см.

Показать подробное решение
Шаг 1: P = 2(a + b) = 50 → a + b = 25. Разность a − b = 1. Решаем систему: a = 13, b = 12.
Шаг 2: Диагональ — высота, значит она перпендикулярна стороне b. В прямоугольном треугольнике: гипотенуза a = 13, катет b = 12.
Шаг 3: Диагональ d = √(13² − 12²) = √(169 − 144) = √25 = 5 см.
Проверка: 5-12-13 — пифагорова тройка ✅

Семья купила LED-телевизор с подставкой глубиной 25 см и соотношением сторон 16:9. Диагональ телевизора — 31,5 дюйм (1 дюйм ≈ 2,54 см). Получится ли поставить этот телевизор в квадратную нишу шириной 74 см и глубиной 35 см?

Задание 14 (№598)

В равнобедренном треугольнике основание равно 10 см, а боковая сторона равна 13 см. Найдите радиус окружности, вписанной в этот треугольник.

Показать подробное решение

⚖️ Задачи на доказательство (идеи)

№587 — площадь равностороннего треугольника
Идея: высота равностороннего треугольника со стороной a равна a√3/2 (через теорему Пифагора: h² + (a/2)² = a²). Тогда S = ½ · a · h = ½ · a · a√3/2 = a²√3/4.
№600 — радиус описанной окружности прямоугольного треугольника
Идея: центр описанной около прямоугольного треугольника окружности лежит в середине гипотенузы (это следует из того, что медиана к гипотенузе равна её половине — доказывается через достройку до прямоугольника). Значит R = c / 2.
№597 — меньшая высота треугольника
Идея: S = ½ · a · hₐ = ½ · b · h_b = ½ · c · h_c. Чем больше сторона, тем меньше высота к ней. Значит меньшая высота — это высота к большей стороне. Для треугольника 24-25-7: 7²+24²=25² — прямоугольный, значит гипотенуза 25 — наибольшая сторона. Меньшая высота h = 7·24/25 = 6,72 см.

🏗 Блок 3. Практическое применение

🎯 Продукт урока: «Архитектор лестницы»

Ты проектируешь лестницу в двухэтажном доме. Высота этажа — 3 м. Лестница должна быть безопасной: угол наклона не слишком крутой. По строительным нормам, на каждый 1 м подъёма нужно минимум 1,2 м горизонтальной длины.

Задача: вычисли минимальную длину лестничного марша (наклонной части) и проверь, что он соответствует нормам.

Показать расчёт архитектора
Шаг 1: Горизонтальная длина: 3 · 1,2 = 3,6 м.
Шаг 2: По теореме Пифагора: L = √(3² + 3,6²) = √(9 + 12,96) = √21,96 ≈ 4,69 м.
Итог: лестничный марш длиной около 4,7 м обеспечит безопасный подъём на 3 м. Если хочется покороче — нужно увеличить угол, но это уже нарушение норм! 🏗️

📝 Главное, что нужно запомнить

  • Теорема Пифагора: c² = a² + b² (в прямоугольном треугольнике).
  • Обратная теорема: если a² + b² = c², то треугольник прямоугольный — это способ проверить прямой угол без транспортира!
  • Пифагоровы тройки: 3-4-5, 5-12-13, 8-15-17, 7-24-25 — выучи наизусть, они экономят время на контрольной.
  • Формула Герона: S = √(p(p−a)(p−b)(p−c)) — площадь треугольника по трём сторонам.
  • Высота прямоугольного треугольника к гипотенузе: h = ab/c (через два выражения площади).
  • Медиана к гипотенузе равна половине гипотенузы (это докажем позже, но помни!).
  • В задачах: сначала определи, где гипотенуза (самая длинная сторона, напротив прямого угла), — от этого зависит формула.

💡 Методическая подсказка (для учителя или родителя)

  • Доказательство теоремы: метод достройки до квадрата — самый наглядный. Вырежьте из бумаги 4 одинаковых прямоугольных треугольника и сложите из них квадрат со стороной (a + b) — внутри останется квадрат со стороной c. Ученик сам увидит равенство площадей!
  • Пифагоровы тройки: предложите ученику «охоту за тройками» — перебрать числа от 1 до 20 и найти все тройки. Это развивает вычислительный навык и даёт интуицию.
  • Главная ошибка: ученики путают, где гипотенуза, и применяют формулу a² + b² = c², подставляя в c не самую длинную сторону. Правило-подсказка: «гипотенуза — царь, она всегда самая большая и всегда напротив прямого угла».
  • Задача №583 (катеты через угол 60°): в 8 классе тригонометрии ещё нет! Решение идёт через свойство угла 30° (из 7 класса) + теорему Пифагора. Это отличная задача на межтемные связи.
  • Задача №588в: «прямоугольный треугольник, высота к гипотенузе 7» — задача с недостаточными данными, если не указано, что треугольник равнобедренный. Обсудите с учеником, почему так.
  • Формула Герона (№590): удобна, когда даны все три стороны, но высоты не известны. Однако она громоздкая — ученики часто ошибаются в арифметике. Предложите сначала проверить, не является ли треугольник прямоугольным (по обратной теореме) — тогда площадь считается проще.
  • Практические задачи (№603, №604): отличный повод обсудить, как математика работает в реальной жизни — от строительства до покупки телевизора.
  • Сильным ученикам: предложите найти все пифагоровы тройки с c ≤ 50 по формуле a = 2mn, b = m² − n², c = m² + n². Это мини-исследование на несколько вечеров.
